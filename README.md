# 🌙 MindMate – Your Personal Mood Chat Companion

**Live Project:** (https://mindmate-lake.vercel.app/)

MindMate is an interactive, mood-based chat companion built using **HTML, CSS, and JavaScript**.  
It allows users to **sign up, log in, and chat** in two different modes — **Introvert** or **Extrovert** — each offering a unique tone and conversation style.

The app aims to create a calming or energetic digital space where users can express themselves freely, track their moods, and practice short relaxation activities like breathing exercises.

---

## ✨ Features

### 🧍‍♀️ User System
- User **Signup & Login** system using `localStorage`.
- Personalized greetings with your name and chat history.

### 💬 Chat Modes
- **Introvert Mode 🌙:** Calm, soothing, reflective tone.
- **Extrovert Mode ✨:** Energetic, expressive, and uplifting tone.

### ❤️ Chatbot Interaction
- Smart responses based on emotional keywords like *sad*, *happy*, *tired*, *stress*, etc.
- Detects crisis-related phrases and provides **emergency helpline info**.
- Real-time typing animation and message history.

### 🌈 Mood Tracker
- Choose how you feel using emojis (e.g., 😄, 😢, 🌧️).
- MindMate responds with empathy and care.

### 🌬️ Breathing Exercise
- Guided breathing animation for relaxation.
- Helps reduce stress and anxiety in just a few seconds.

### 🔁 Mode Switching
- Instantly switch between Introvert and Extrovert modes for a fresh session.

### 🚪 Logout
- Securely logout anytime with one click.
